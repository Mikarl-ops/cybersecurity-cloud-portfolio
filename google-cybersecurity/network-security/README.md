# Wireshark investigation walkthrough

This is a written example of a packet-analysis workflow. The repository does not include a PCAP, packet screenshots, or independently verifiable capture results. The addresses and traffic counts in the narrative are illustrative.

The walkthrough shows how an analyst could filter TCP SYN packets, inspect conversations, and search for cleartext HTTP authentication. To reproduce the investigation, use a lawful, sanitized capture and record the capture source, time range, filters, relevant packet numbers, and limitations. Avoid sharing real user credentials or sensitive packet payloads.
